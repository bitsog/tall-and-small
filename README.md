# Tall and Small Yard Work

A simple, mobile-friendly, no-dependencies landing page for David's yard work business.

## Website

- `index.html` — the whole website, including call/text buttons and illustrative services.
- `logo.png` — the original Tall and Small logo. Upload this exact PNG to the repository root before publishing. Do not replace it with generated or stock artwork.

## Publish for free

1. Verify `index.html` and `logo.png` both exist on `main`.
2. In GitHub Settings > Pages, select **Deploy from a branch** → **main** → **/(root)**, then Save.
3. Visit https://bitsog.github.io/tall-and-small/ from a phone and verify logo, call, and text actions.
4. Confirm services and phone number with David before widely promoting the website.
5. Generate the final static QR code only after verifying the website address works.

## Maintenance

Edit `index.html` on GitHub to update services or wording. No build tools, database, paid service, or external runtime dependencies are required.
